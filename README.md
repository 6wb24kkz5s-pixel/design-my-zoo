# Design My Zoo

A blocky, top-down zoo-building game for Primary 3 Science.
Students build homes for 12 animals and choose materials that suit each job.

**Live link:** https://6wb24kkz5s-pixel.github.io/design-my-zoo/

## Run it on your computer
You need [Node.js](https://nodejs.org) installed. In a terminal, inside this folder:

```
npm install
npm run dev
```

Then open the link it shows (for example `http://localhost:5173/design-my-zoo/`).

## Try the dev version on an iPad
Your computer and the iPad must be on the same Wi-Fi.

```
npm run dev -- --host
```

It shows a "Network" link such as `http://192.168.1.20:5173/design-my-zoo/`.
Type that link into Safari on the iPad.

## How updates go live
Push changes to the `main` branch on GitHub. After about 2 minutes the live link updates.
If the checks fail, the live link stays on the last working version.
